# ⚡ Skills Quick Reference - Tarjeta Rápida

## 📋 Impeccable - Código Perfecto

```bash
# Validar código
/impeccable validate --file src/ --strict true

# Auto-formatear
/impeccable format --directory src/ --auto-fix true

# Analizar
/impeccable analyze --file app.jsx

# Reportar
/impeccable report --severity critical
```

**Niveles**: `basic` | `intermediate` | `strict`  
**Tiempo**: 30-60 segundos  
**Cuándo usar**: Antes de commit importante

---

## 🎨 Emil Kowalski - UI/UX Moderno

```bash
# Crear componente
/emilkowalski create-component button --style modern

# Diseñar página
/emilkowalski design-page --name "dashboard"

# Agregar animaciones
/emilkowalski animate --component "card" --effect "fade-slide"

# Validar accesibilidad
/emilkowalski validate-a11y --file src/components/
```

**Componentes**: Button, Input, Card, Modal, Navbar  
**Temas**: Minimal, Neomorphic, Glassmorphism  
**Cuándo usar**: Diseñar nuevo componente o página

---

## 🎭 Taste Skill - Buen Gusto

```bash
# Analizar diseño
/taste-skill analyze --url "website.com" --criteria "typography,color,spacing"

# Crítica constructiva
/taste-skill critique --file "design.figma" --suggest-improvements true

# Aprender
/taste-skill learn --topic "typography" --style practical

# Ejercicio
/taste-skill exercise --type comparison --difficulty intermediate
```

**Tópicos**: Typography, Color, Spacing, Components, Accesibility  
**Niveles**: Beginner → Intermediate → Advanced → Master  
**Cuándo usar**: Mejorar criterios de diseño

## 🔥 Combinaciones Poderosas

### Workflow: Feature Completa
```bash
/gsd --task "Nueva feature"
/impeccable validate --strict true
/emilkowalski design-page (si es UI)
/review
/ultrareview
```

### Workflow: Refactor Profesional
```bash
/taste-skill critique --file "src/"
/impeccable format --level strict
/emilkowalski refactor-ui (si es UI)
/ultrareview --compare main...branch
```

### Workflow: Desarrollar Gusto
```bash
/taste-skill learn --topic "typography"
/taste-skill exercise --type analysis
/emilkowalski create-component (aplicar aprendizaje)
/impeccable validate
```

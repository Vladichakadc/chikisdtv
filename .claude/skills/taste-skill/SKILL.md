# Taste Skill - Desarrollar Buen Gusto en Diseño 🎭

Skill para cultivar y aplicar excelentes criterios de diseño, desarrollando un ojo crítico para la belleza, elegancia y usabilidad.

## Qué es "Buen Gusto"

Buen gusto = Equilibrio entre:
- **Función** (¿Funciona bien?)
- **Forma** (¿Se ve bien?)
- **Contexto** (¿Es apropiado?)
- **Propósito** (¿Logra su objetivo?)

## 5 Principios Fundamentales

### 1. Simplicidad Elegante
```
❌ Complejo
✅ Simple pero sofisticado
```

**Ejercicio**: Reducir un diseño a su esencia.

### 2. Propósito Antes que Forma
```
❌ Bonito pero confuso
✅ Funcional y hermoso
```

**Ejercicio**: Describir el propósito en 1 frase.

### 3. Coherencia Visual
```
❌ Estilos mezclados sin razón
✅ Lenguaje visual consistente
```

**Ejercicio**: Crear sistema de diseño unificado.

### 4. Espacio Estratégico
```
❌ Todo lleno
✅ Respiro visual inteligente
```

**Ejercicio**: Agregar espacio en blanco significativo.

### 5. Escala y Proporción
```
❌ Elementos desproporcionados
✅ Jerarquía visual clara
```

**Ejercicio**: Aplicar ratio de oro (1.618).

## Lecciones Clave

### Tipografía con Gusto

#### ✅ Bueno
- 2-3 familias máximo
- Contraste claro (display + body)
- Tamaño adecuado (16px+ body)
- Interlineado generoso (1.5-1.8)
- Ancho línea 50-75 caracteres

#### ❌ Malo
- 5+ familias de fuentes
- Todo igual tamaño
- Texto pequeño (< 14px)
- Interlineado apretado
- Líneas muy largas (>100 chars)

### Color con Criterio

#### ✅ Bueno
- Paleta limitada (3-5 colores)
- Contraste WCAG AA+ (4.5:1)
- Colores con propósito
- Coherencia cromática
- Accesibilidad para daltónicos

#### ❌ Malo
- Arco iris descontrolado
- Bajo contraste
- Colores al azar
- Inconsistencia
- Inaccessible

### Espaciado Inteligente

#### ✅ Bueno
- Escala consistente (8px, 16px, 24px...)
- Relacionados entre sí
- Respeto por el espacio negativo
- Breathing room alrededor de elementos
- Jerarquía clara

#### ❌ Malo
- Espaciados aleatorios
- Elementos amontonados
- Sin lógica visual
- Parece accidental
- Falta de jerarquía

## Ejercicios de Entrenamiento

### Ejercicio 1: Análisis Comparativo
```bash
/taste-skill exercise comparison
  --design-a "apple.com"
  --design-b "competitor.com"
  --criteria "visual-hierarchy,spacing,color"
```

**Lo que aprenderás**: Identificar diferencias sutiles.

### Ejercicio 2: Crítica Constructiva
```bash
/taste-skill exercise critique
  --design "your-project"
  --focus "typography"
  --actionable true
```

**Lo que aprenderás**: Dar y recibir feedback.

### Ejercicio 3: Rediseño Minimalista
```bash
/taste-skill exercise minimize
  --original "your-design"
  --target "50% menos elementos"
  --maintain-function true
```

**Lo que aprenderás**: Simplicidad elegante.

### Ejercicio 4: Restricciones Creativas
```bash
/taste-skill exercise constraints
  --rule "solo 2 colores"
  --or "solo tipografía sans-serif"
  --design "your-project"
```

**Lo que aprenderás**: Creatividad bajo presión.

## Anti-patrones Comunes

| Anti-patrón | Por qué está mal | Solución |
|-------------|------------------|----------|
| Skeuomorfismo excesivo | Anticuado | Flat/Minimal design |
| Gradient abusivo | Distrae | Colores sólidos cuidados |
| Sombras densas | Pesado | Sombras sutiles |
| Animaciones excesivas | Distrae | Movimiento con propósito |
| Tipografía pequeña | Ilegible | Jerarquía clara |

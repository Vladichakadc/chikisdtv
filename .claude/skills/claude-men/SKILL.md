# Claude Mentorship (claude-men) 👨‍🏫

Skill de mentoría especializada para aprender mejores prácticas de desarrollo de software.

## Áreas de Mentoría

### 1. Arquitectura de Software
- Diseño de sistemas escalables
- Patrones de diseño
- Decisiones arquitectónicas
- Refactoring estratégico

```bash
/claude-men architecture --topic "arquitectura de microservicios"
```

### 2. Code Quality
- Mejores prácticas de código
- Testing estratégico
- Rendimiento y optimización
- Seguridad del código

```bash
/claude-men quality --review-code true
```

### 3. Development Workflow
- Git workflows efectivos
- CI/CD best practices
- Code review strategies
- Deployment patterns

```bash
/claude-men workflow --aspect "git-flow"
```

### 4. Problem Solving
- Debugging estratégico
- Root cause analysis
- Problem decomposition
- Solution validation

```bash
/claude-men problem-solving --issue "descripción"
```

### 5. Career Development
- Skill progression
- Technical leadership
- Decision making
- Career planning

```bash
/claude-men career --goal "objetivo"
```

## Formato de Mentoría

### Pre-Session
- Evaluación de nivel actual
- Identificación de gaps
- Fijación de objetivos

### During Session
- Enseñanza interactiva
- Ejemplos prácticos
- Feedback en tiempo real
- Guidance personalizada

### Post-Session
- Resumen de aprendizajes
- Recursos recomendados
- Ejercicios de práctica
- Plan de mejora

## Ejemplos

### Ejemplo 1: Aprender Testing
```bash
/claude-men
  --topic "testing"
  --level intermediate
  --style hands-on
```

Proporciona:
- Conceptos clave
- Ejemplos en tu stack
- Ejercicios prácticos
- Patrones comunes

### Ejemplo 2: Code Review Guidance
```bash
/claude-men
  --topic "code-review"
  --code-sample path/to/code
  --focus "performance"
```

Proporciona:
- Análisis detallado
- Mejoras sugeridas
- Explicación de por qué
- Recursos de aprendizaje

### Ejemplo 3: Architecture Decision
```bash
/claude-men
  --topic "architecture"
  --context "proyecto-actual"
  --decision "usar microservicios vs monolito"
```

Proporciona:
- Análisis de opciones
- Trade-offs
- Recomendación
- Plan de implementación

## Ejemplo de Sesión

```bash
/claude-men
  --topic "React Performance"
  --current-level "intermediate"
  --goal "optimizar renders en app grande"
  --time 60m
```

**Salida:**
1. Diagnóstico de nivel actual
2. Conceptos clave (15 min)
3. Ejemplos prácticos (20 min)
4. Feedback y mejoras (15 min)
5. Plan de seguimiento (10 min)

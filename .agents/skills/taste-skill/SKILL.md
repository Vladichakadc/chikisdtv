# Taste Skill - Desarrollar Buen Gusto en Diseño 🎭

Skill para cultivar y aplicar excelentes criterios de diseño, desarrollando un ojo crítico para la belleza, elegancia y usabilidad.

## Qué es "Buen Gusto"

Buen gusto = Equilibrio entre:
- **Función** (¿Funciona bien?)
- **Forma** (¿Se ve bien?)
- **Contexto** (¿Es apropiado?)
- **Propósito** (¿Logra su objetivo?)

## 5 Principios Fundamentales

### 1. Simplicidad Elegante
```
❌ Complejo
✅ Simple pero sofisticado
```

### 2. Propósito Antes que Forma
```
❌ Bonito pero confuso
✅ Funcional y hermoso
```

### 3. Coherencia Visual
```
❌ Estilos mezclados sin razón
✅ Lenguaje visual consistente
```

### 4. Espacio Estratégico
```
❌ Todo lleno
✅ Respiro visual inteligente
```

### 5. Escala y Proporción
```
❌ Elementos desproporcionados
✅ Jerarquía visual clara
```

## Uso

### Analizar Diseño Existente
```bash
/taste-skill analyze

  --criteria "typography,color,spacing"
```

### Mejorar Diseño
```bash
/taste-skill critique

  --detail level-3
  --suggest-improvements true
```

## Lecciones Clave

### Tipografía con Gusto

#### ✅ Bueno
- 2-3 familias máximo
- Contraste claro (display + body)
- Tamaño adecuado (16px+ body)
- Interlineado generoso (1.5-1.8)
- Ancho línea 50-75 caracteres

#### ❌ Malo
- 5+ familias de fuentes
- Todo igual tamaño
- Texto pequeño (< 14px)
- Interlineado apretado

### Color con Criterio

#### ✅ Bueno
- Paleta limitada (3-5 colores)
- Contraste WCAG AA+ (4.5:1)
- Colores con propósito
- Coherencia cromática

#### ❌ Malo
- Arco iris descontrolado
- Bajo contraste
- Colores al azar

### Espaciado Inteligente

#### ✅ Bueno
- Escala consistente (8px, 16px, 24px...)
- Respeto por el espacio negativo
- Jerarquía clara

#### ❌ Malo
- Espaciados aleatorios
- Elementos amontonados

## Anti-patrones Comunes

| Anti-patrón | Por qué está mal | Solución |
|-------------|------------------|----------|
| Skeuomorfismo excesivo | Anticuado | Flat/Minimal design |
| Gradient abusivo | Distrae | Colores sólidos cuidados |
| Sombras densas | Pesado | Sombras sutiles |
| Animaciones excesivas | Distrae | Movimiento con propósito |
| Tipografía pequeña | Ilegible | Jerarquía clara |

# Marketing & Growth Loops

You are an expert in growth loop design. Your goal is to help design systems where users naturally bring in more users — creating compounding, self-sustaining growth.

## What Is a Growth Loop?

A growth loop is a cyclical process where output from one user action becomes the input that brings in new users.

**Linear model:** Ads → User (stops here)  
**Loop model:** Ads → User → Action → New User → (repeat)

Loops compound. Linear doesn't.

---

## Types of Growth Loops

### 1. Viral/Word-of-Mouth Loop
Users invite others or share content that drives new users.

**Trigger points:**
- Collaboration features (invite a teammate)
- Social sharing of results ("I just hit [milestone] on [product]!")
- Content creation that's inherently shareable

**Metrics:** Viral coefficient (K-factor) = Invitations sent × Invitation conversion rate

**K > 1** = viral growth  
**K = 0.5** = each user brings in 0.5 more (still valuable, just not exponential)

### 2. Content Loop
Users create content that attracts new users who then create more content.

**Examples:**
- YouTube: Users upload → viewers discover → become creators → upload
- Notion: Users create templates → shared publicly → new users discover
- Figma: Users share designs → viewed by collaborators → sign up

**Building it:** Make user-generated content publicly accessible and indexable.

### 3. SEO Loop
Content creates organic traffic → converts to users → users create content.

**Example:**
- Users create profiles/listings → profiles rank on Google → new visitors sign up → create profiles

### 4. Product-Led Growth (PLG) Loop
Product usage itself drives acquisition.

**Types:**
- **Collaboration**: Invite to collaborate creates new users
- **Network effect**: More users makes product more valuable
- **Sharing/export**: Output is branded with your product (Calendly links, Typeform embeds)
- **API/integration**: Developers embed your product, expose it to their users

### 5. Paid Loop
Revenue → Paid acquisition → More revenue (if LTV > CAC with enough margin).

**Requirements:** CAC payback period short enough that you can reinvest quickly.

## Designing Your Loop

### Step 1: Identify Natural Sharing Moments
When do users naturally want to share or invite others?
- "I just created/achieved something"
- "I need a colleague's input"
- "I want to show this off"
- "I need someone else to use this to get value"

### Step 2: Reduce Friction in the Loop
For each step in the loop:
- What's the barrier to the next action?
- How can you remove it?
- What's the minimum viable action?

### Step 3: Add Incentives
Make the loop action rewarding:
- Social recognition (leaderboards, badges)
- Functional value (collaboration works better with more people)
- Economic reward (referral incentive)
- Emotional reward (sharing an accomplishment)

## Loop Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| Viral coefficient (K) | New users per existing user | > 0.5 is great, > 1 is viral |
| Cycle time | How long for one loop to complete | Shorter = faster compounding |
| Loop conversion rate | % who complete each loop step | Maximize at each step |
| Payback period (paid loop) | Months to recover CAC | < 12 months for most |

---

## Common Loop Pitfalls

1. **Designing for power users**: Most users won't go viral — design for the median user
2. **Ignoring cycle time**: A K of 0.8 with a 1-day cycle beats K of 0.9 with a 30-day cycle
3. **Forcing it**: Loops that feel unnatural get ignored
4. **Single loop dependency**: Most companies need both acquisition loops AND retention loops
